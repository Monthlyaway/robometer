**一、 选题的目的和意义**

在具身智能与强化学习的领域，长程任务的稀疏奖励构成了核心挑战。在这些任务中，环境通常仅提供极度稀疏的奖励信号（Sparse Rewards），即策略仅在最终状态满足任务终止条件时获得奖励（例如返回 1，其余所有时间步均返回 0）。这种时序上的稀疏性导致策略网络很难通过探索达到成功状态。

另一方面，在在线真机强化学习部署中，物理硬件的运行严格受限于真实时间，无法像仿真环境那样实例化大量独立进程进行高并发的仿真模拟。这导致了transition的采样吞吐量极小，实际探索效率远低于仿真，从而使长程任务中策略梯度的收敛延迟呈指数级增加。

为了克服真机环境中样本获取成本高与稀疏奖励导致的策略搜索空间过大问题，当前研究主要通过引入人类示范数据（Demonstration Data）来限制智能体在训练初期的动作分布。具体而言，针对真机探索效率低下的挑战，目前的解决方案主要沿着以下几条技术路线展开：

1.  采用交互式模仿学习（Interactive Imitation
    Learning）范式，例如HG-DAgger算法[1]。该方法的执行步骤首先是利用人类专家数据集进行Behavioral Cloning，通过监督学习预训练一个基础策略网络。在随后的在线部署采集中，由于行为克隆存在因数据分布不匹配导致的误差累积问题，当基础策略将系统引入未见过的危险状态空间时，人类专家会接管控制权，塑造系统返回安全状态区域。在此接管期间收集的纠正状态-动作对会被添加至数据集中，用于重新训练策略网络。这种方法在初期利用人类专家控制系统，避免了随机探索带来的硬件风险与低样本利用率。然而，其局限性在于策略优化的上限受制于所收集的人类标签质量，并且交互式数据采集过程要求人类专家在整个控制周期内持续评估系统状态，极大增加了在线数据采集的成本。

2.  直接将人类示范数据注入强化学习的在线训练回路中，以HIL-SERL及其底层的RLPD算法为典型代表[2]。该方法在实现上维护了两个缓冲区：一个存储离线收集的人类示范轨迹，另一个存储策略网络在环境中执行收集的在线交互数据。在计算策略梯度时，算法在构建训练批次时强制从这两个缓冲区中进行1:1的等比例采样。同时，在线收集数据时，算法引入了人类在环（Human-in-the-loop）机制------操作员可以随时切断策略网络的控制输出，由人类接管并产生新的修正轨迹存入缓冲区。在训练早期，通过高频率的人类介入替代了策略的随机探索。

因此，无论是基于模仿学习，还是基于人工干预的强化学习，其底层思路均试图通过在线获取人类示范来强行指引策略网络收敛。这些方法虽然有效避免了完全随机探索，但共同面临着高昂的在线人类专家监督成本，无法实现真正的自主高效探索。为了在无需频繁在线人工干预的前提下解决上述问题，需要回到约束条件本身：真机环境的核心矛盾在于采样吞吐量固定且极低，策略收敛速度完全取决于每一条 transition 所携带的梯度信息密度。在稀疏奖励下，绝大多数 transition 的奖励信号为零，梯度几乎无法传播，使有限的采样预算被大量浪费。因此，在不增加真机交互次数的前提下加速收敛的唯一可行路径，是为每个时间步提供有效的学习信号------这正是稠密奖励塑造（Dense Reward Shaping）的核心作用。必须在马尔可夫决策过程（MDP）的底层环境反馈机制中引入 Dense Reward Shaping，才能从根本上将有限的采样吞吐量利用率最大化，克服长程任务中的成功状态不可达现象。

在当前的Dense Reward Shaping研究中，主要存在四种典型技术路径。第一类是基于几何与启发式规则的手工设计，该方法通过直接读取底层状态（如物体坐标、接触力）来计算奖励；其计算效率虽高，但需要针对每个具体任务硬编码距离或接触条件，缺乏跨任务的泛化能力。第二类是利用视觉-语言模型（VLM）进行零样本（Zero-shot）打分的方法[3]，通过计算当前环境图像的像素特征与自然语言提示在隐式特征空间中的余弦相似度来生成奖励。第三类是通过大语言模型进行代码生成与上下文进化搜索的方法[4]，直接生成可执行的奖励函数代码。第四类则是利用演示数据拟合势能函数[5],[6]。相比之下，第四类方法通过提取底层的运动学规律与帧间时间距离，能更有效地将专家先验转化为单步的马尔可夫奖励信号，具有更高的理论可行性与研究潜力。

然而，现有的势能与隐式进度模型在实际应用中暴露出两个核心缺陷。

1.  奖励投机（Reward Hacking）：现有方法的训练数据仅包含成功轨迹，reward
    model 从未见过任务失败或状态倒退的样本，因此无法在失败边界附近给出正确的惩罚信号。策略在探索中一旦进入「看起来接近目标但实际已脱手」的状态，reward model 仍会给出虚高分数，策略便停留于此、不再推进[6], [7]。

2.  势能与真实进度脱节：现有方法（如直接回归绝对进度值）仅约束势能的端点数值，并未对相邻状态之间的势能差值与物理时间跨度的比例关系作出任何约束。这导致势能函数在任务中段的梯度分布极不均匀------某些区域惩罚过重使策略过早收敛，另一些区域梯度过于平坦使探索停滞。

上述两个缺陷有各自独立的根因：前者源于训练数据缺乏对失败边界的覆盖，后者源于训练目标缺乏对时序单调比例的显式约束。

为解决上述挑战，本研究提出了一种基于演示倒放负样本合成与时序比例排序的势能奖励框架。该框架将离线自监督的势能函数学习与在线强化学习探索相集成，旨在克服真机长程任务中因稀疏奖励导致的探索低效问题。具体而言，本方法利用演示倒放（Video Rewinding）技术，直接从专家成功轨迹中自动化合成具有物理倒退意义的负样本序列，从而为系统补充缺失的失败边界。基于这些增广专家数据，我们利用物理时间跨度作为排序约束，训练出一个能够准确反映底层任务进度的严格单调参数化势能函数。在线部署阶段，冻结该势能网络并计算相邻状态转移间的势能差值，将其作为稠密奖励信号接入 SAC 算法。基于 PBRS 理论，这种势能差分机制不仅在数学上保证了原 MDP 最优策略集的不变性，还能有效抑制 Reward Hacking 现象，大幅提升长程任务的在线探索与样本利用效率。

本研究的核心贡献体现在以下两点。

1.  在势能函数的训练目标上，现有的直接进度回归方法（如ReWiND）仅约束势能的绝对数值，而基于对比学习的方法（如GCR）仅拉近或推远目标状态的表征，均未对相邻状态间势能差值与物理时间跨度的比例关系作出显式约束。本研究在演示倒放增广数据的基础上，设计了一种排序训练目标：两个状态在势能函数上的输出差距，应当与它们在原始轨迹中相距的时间步数成正比------离得越远的状态对，势能差越大；相邻的状态对，势能差则保持细微。这一约束使势能函数的\"刻度\"与真实的任务推进速度对齐。

2.  在系统层面，本研究将演示倒放负样本合成、时序比例自监督排序训练与基于PBRS理论的差分奖励三个模块整合为面向真机长程任务的完整闭环框架，在仅依赖少量离线专家轨迹、无需频繁在线人工干预的前提下，为SAC算法提供稠密的探索梯度。

**二、 国内外相关研究状况综述**

Ng 等人提出的基于势能的奖励塑造（PBRS）从数学上证明了，只要将塑造奖励构造为状态势能函数的折扣差值形式，原 MDP 的最优策略集便不会发生改变[8]。早期的逆向强化学习（IRL）[9]与基于偏好的强化学习（PbRL）[10]虽尝试从数据中恢复奖励，但受限于极高的人工标注与计算成本。

2024 年，基础模型的引入改变了这一现状。VLM-RM 率先利用视觉-语言模型，通过计算当前图像与自然语言指令在特征空间中的余弦相似度，直接输出稠密奖励，摆脱了对底层物理状态坐标的依赖[3]。同期，Eureka 系统将环境源代码作为输入，利用大语言模型的零样本能力执行上下文进化搜索，实现了可执行奖励函数代码的自动生成。这两条路线确立了利用多模态对齐和代码生成构建密集奖励的基础[4]。

后续研究主要致力于修复reward不稳定与贪心搜索陷入局部最优两个缺陷。针对视觉对齐的数值不稳定问题，RL-VLM-F 放弃了直接标量打分，转而采用两阶段查询：先令 VLM 执行自然语言描述分析，随后输出二元偏好标签，再通过拟合偏好数据生成平滑的奖励模型，有效解决了形变物体操作中reward分配问题[11]。RoboCoT 则进一步引入机器人思维链，将宏观任务指令分解为细粒度子目标，并显式注入失败特征以构建惩罚边界[12]。在基于 LLM 的代码生成方法中，针对 Eureka 贪心迭代导致的历史数据浪费与易陷入局部最优的问题，RF-Agent 将奖励设计转化为顺序决策过程，并引入蒙特卡洛树搜索（MCTS）框架，在扩展阶段将局部变异与全局跨节点交叉、路径推理等动作相结合，从而显著提升了探索效率与奖励搜索的效率[13]。

然而，尽管视觉语言模型降低了奖励设计成本，但由于其忽略了底层物理状态的连续流形，极易引发策略层面的奖励投机（Reward Hacking）。智能体学会了停留在视觉相似的静态位置骗取高分，而并未完成物理交互。为此，研究重心转向对物理时序进度的直接建模。Diffusion Reward 用扩散模型中的负条件熵作为塑造，强迫在线探索策略严格约束于专家行为的数据分布内[14]；TimeRewarder 训练网络直接预测两帧视频之间的物理时间距离，并将其转化为差分进度[5]。

此外，如果奖励模型仅仅依赖这些高质量的成功演示进行训练，它将严重过拟合于理想轨迹。当策略在探索过程中到达\"接近目标却最终脱手\"的状态（Near-misses），过拟合的奖励模型往往会给出错误的高估分数，从而引发严重的策略投机（Reward Hacking）。GCR 针对\"画面看起来像成功，但实际失败\"的虚假状态，主动提取这些失败轨迹的末端作为负样本[6]；ReWiND 引入了演示倒放操作，人为合成倒退的物理轨迹，弥补了专家数据缺乏失败样本的缺陷[15]。

综上所述，当前的奖励塑造研究已从基于单帧静态图像的绝对相似度打分，发展为对底层物理时序连续性的相对约束；从单纯依赖成功演示，转向通过主动合成负样本来描绘失败边界。然而，现有方法在实际部署中仍存在两点关键缺口：其一，时序建模与负样本合成尚未被系统性地整合进同一个自监督训练框架；其二，现有势能函数的训练缺乏对物理时间跨度的显式比例约束，导致势能差值无法准确反映真实的任务进度距离，在真机长程任务中极易引发奖励不稳定与策略停滞。上述不足表明，构建一个能够同时具备结构化失败边界与严格单调时序约束的势能奖励框架，是当前真机强化学习领域亟待解决的核心问题。

**三、 研究方法**

本方法在底层执行上分为离线自监督学习与在线强化学习两个阶段。

离线自监督排序学习阶段：不依赖人工标量数值标注，直接提取专家轨迹的底层物理状态发生顺序作为监督信号。通过对专家成功轨迹执行演示倒放切分，显式生成违反物理任务目标的倒退行为状态序列。在此增广数据上，训练一个参数化网络将底层连续状态映射到严格约束于
$\left\lbrack 0,1 \right\rbrack$的势能空间，并通过时序比例排序算法，强制网络输出的势能差拟合物理世界真实时间流逝的先后顺序。

在线强化学习阶段：冻结势能网络权重。在智能体与环境交互时，将连续状态输入网络获取单步势能差，按照基于势能的奖励塑造（PBRS）理论，将其与稀疏环境奖励进行相加组合，从而为 Soft Actor-Critic (SAC) 算法的策略更新提供稠密的探索梯度。

**3.1 演示倒放机制与负样本增广**

为构建完整的时序流形，系统首先需要对只有正向目标的专家数据进行扩增。定义原始专家成功轨迹为底层状态序列
$\tau = (s_{1},s_{2},\ldots,s_{T})$。对其进行演示倒放数据扩增的步骤如下：

1.  在区间 $\left( 1,T \right)$内均匀采样切断点索引 $i$，并在区间$\left( 1,i \right)$内随机采样倒放步数 $k$。

2.  序列拼接：提取前向执行子序列 $S_{\text{forward}} = (s_{1},\ldots,s_{i})$，并提取 $s_{i}$之前的动作序列进行逆序处理，生成倒放子序列 $S_{\text{rewind}} = (s_{i - 1},\ldots,s_{i - k})$。将两者拼接得到增强状态序列 $\widetilde{\tau} = \lbrack S_{\text{forward}},S_{\text{rewind}}\rbrack$。

3.  分配进度标签：为 $\widetilde{\tau}$中的每一个物理状态分配其在原始绝对时间轴上的进度值，构建标签序列
    $P$：

$$P = (1,2,\ldots,i,i - 1,\ldots,i - k)$$

通过该方法，序列 $\widetilde{\tau}$显式包含了一段符合物理运动学规律的执行失败并退回的负样本轨迹。对于序列中任意采样的状态对 $\left( s_{u},s_{v} \right)$，其物理真实进度差即为 $\Delta P_{uv} = P_{v} - P_{u}$。网络在后续优化中可通过判断 $\Delta P_{uv}$的正负号，精准获取物理状态倒退的惩罚梯度。

**3.2 势能函数的自监督排序优化**

参数化势能函数定义为
$\Phi_{\theta}(s)$。系统在离线阶段对该网络执行自监督优化，其总损失函数由以下三部分约束共同组成：

$$\mathcal{L(}\theta) = \mathcal{L}_{\text{rank}} + \mathcal{L}_{\text{bc}} + \mathcal{L}_{\text{smooth}}$$

**1. 时序比例排序损失（**$\mathcal{L}_{\text{rank}}$**）**

为了避免固定边距在长序列中累加导致的输出边界冲突，引入基于相对时间跨度的边距。从增强序列
$\widetilde{\tau}$中随机采样两个状态 $s_{u}$与 $s_{v}$，提取其对应的进度标签 $P_{u}$与 $P_{v}$。定义时间边距：

$$m(u,v) = c \cdot \frac{P_{v} - P_{u}}{T_{\max}}$$

其中 $\left. \ c \in (0,1 \right\rbrack$为缩放系数，$T_{\max}$ 为数据集中轨迹的最大长度。排序损失采用 Pairwise Logistic 回归形式计算：

$$\mathcal{L}_{\text{rank}} = \mathbb{E}\left\lbrack - \log\sigma\left( \Phi_{\theta}(s_{v}) - \Phi_{\theta}(s_{u}) - m(u,v) \right) \right\rbrack$$

该执行逻辑不仅强制后续物理状态的势能大于前序状态，且要求其差值与物理时间跨度成正比。如果采样 $S_{\text{rewind}}$中的状态与 $S_{\text{forward}}$中的状态导致进度标签出现 $P_{u} > P_{v}$，则网络被强制要求输出 $\Phi_{\theta}(s_{u}) > \Phi_{\theta}(s_{v})$，从而利用倒放序列直接赋予负向梯度。

**2. 边界标定损失（**$\mathcal{L}_{\text{bc}}$**）**

为避免网络输出极值，对轨迹的起始状态 $s_{\text{start}}$和终止目标状态 $s_{\text{success}}$施加约束：

$$\mathcal{L}_{\text{bc}} = \left( \Phi_{\theta}(s_{\text{start}}) - 0 \right)^{2} + \left( \Phi_{\theta}(s_{\text{success}}) - 1 \right)^{2}$$

**3. 平滑约束损失（**$\mathcal{L}_{\text{smooth}}$**）**

为抑制势能函数在相邻物理状态点上产生振荡，对连续的时间步状态序列计算二次惩罚：

$$\mathcal{L}_{\text{smooth}} = \mathbb{E}_{\mid P_{u} - P_{v} \mid = 1}\left\lbrack \left( \Phi_{\theta}(s_{v}) - \Phi_{\theta}(s_{u}) \right)^{2} \right\rbrack$$

**四、难点与可行性分析**

本研究的实验验证面临任务选取与基线对齐两方面挑战。在任务选取上，需要筛选具有足够长程性（使稀疏奖励问题显著）且状态空间连续、物理边界清晰的操作任务，以确保倒放机制能生成有意义的负样本；过于简单的任务会导致稀疏奖励问题不突出，从而无法体现方法的优势。在基线对齐上，ReWiND依赖图像输入与语言条件，GCR依赖VIP预训练骨干，与本方法的底层状态输入存在模态差异，如何在保证公平对比的前提下设计统一的评估协议，是实验设计的核心难点。

根据PBRS公式

$$r_{\text{shape}} = \gamma\text{ }\Phi(o_{t + 1}) - \Phi(o_{t})$$

当智能体在探索过程中卡在某处导致状态未发生改变（即 $o_{t + 1} = o_{t}$）时，塑造奖励退化为：

$$r_{\text{shape}} = \Phi(o_{t})(\gamma - 1)$$

因为 $\gamma < 1$且 $\Phi \in \lbrack 0,1\rbrack$，这始终是一个负值。这意味着PBRS本质上对所有静态行为施加了时间惩罚。当 $\Phi(o_{t})$处于高位（接近终点）时，该静态惩罚的绝对值会显著增大。对此，本研究计划通过调节势能函数输出的动态范围与缩放系数 $c$来控制惩罚幅度，并在SAC的熵系数调度上进行针对性的消融实验。

**五、预期成果与形式**

1.  **算法与代码库**：在开源框架RLinf（https://github.com/RLinf/RLinf）上实现完整的离线自监督势能训练模块与在线SAC接入模块，代码将以可复现形式开源，包含数据增广流程、损失函数实现及超参数配置文档。

2.  **实验结果**：在至少一个具有稀疏奖励特性的连续控制任务上，与ReWiND、GCR等基线方法进行定量对比，验证本方法在样本效率与最终成功率上的改进。

3.  **学术论文**：撰写\"时序单调势能奖励：基于倒放增广与比例排序的稠密奖励塑造\"的学术论文一篇，目标投稿至具身智能或强化学习相关方向会议或期刊。
